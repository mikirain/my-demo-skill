# Pi

Pi is an extensible AI agent that works from your terminal. Give it a goal and a working folder, and it can inspect files, run commands, edit content, and work through multi-step tasks.

Use Pi for software development, research notes, writing projects, data files, or hobby work. You can use Pi as is, prompt it to adapt itself to your workflow, or build other applications powered by Pi using the SDK.

## Start using Pi

New to Pi? Follow the [Quickstart](快速入门.md) to install Pi, connect a model, and complete your first task.

If Pi is already installed, choose what you want to do:

- [Use Pi interactively](../指南/运行Pi/在终端中使用Pi.md) to add files, run commands, direct ongoing work, and export results.
- [Choose a model](../指南/运行Pi/选择模型.md) or connect a subscription, API key, local model, or compatible endpoint.
- [Continue or branch a session](../指南/运行Pi/管理会话和上下文.md) to resume work or explore another approach without losing history.
- [Configure Pi](../指南/自定义Pi/配置Pi.md) for your preferences, working folders, instructions, and reusable resources.
- [Understand how Pi works](工作原理.md), including tools, context, sessions, and the agent loop.

## Customize Pi

Pi can reuse prompts, load specialized instructions, add executable integrations, change its terminal interface, connect model services, and distribute these resources as packages.
Use the [Quickstart customization chooser](快速入门.md#choose-how-to-customize-pi) to select the smallest mechanism that meets your need.

## Automate or embed Pi

- Use [print mode](../参考/CLI命令.md#invocation-and-output) for one-off and scripted tasks.
- Use [JSON event stream mode](../参考/JSON事件流.md) to consume structured events from one run.
- Use [RPC mode](../参考/RPC协议.md) to control a separate Pi process.
- Use the [TypeScript SDK](../指南/基于Pi构建/使用SDK.md) to run Pi inside an application.

## Work safely

Pi's tools and extensions run with the permissions of the Pi process. Project trust controls which project resources Pi loads, but it does not sandbox tool calls. Review [Security](../指南/运行Pi/安全运行Pi.md) before using untrusted files, repositories, extensions, or unattended automation.
