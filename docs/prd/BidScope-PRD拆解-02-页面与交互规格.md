## 3. 设计系统

### 3.1 色彩 token（单色骨架 + 单一强调色 + 语义色）

| Token | 值 | 用途 |
| --- | --- | --- |
| `--bg` | `#ffffff` | 页面底色 |
| `--bg-subtle` | `#f6f6f7` | 次级区块、表头、侧栏 |
| `--surface` | `#ffffff` | 卡片 |
| `--ink` | `#111214` | 主文本（对比 17:1） |
| `--ink-2` | `#4b4f56` | 次要文本（8.5:1） |
| `--ink-3` | `#767b83` | 辅助文本（4.6:1，仅 ≥14px） |
| `--line` | `#e5e6e9` | 1px 分隔线、卡片边框 |
| `--line-strong` | `#c9ccd1` | 表格强调线、输入框边框 |
| `--accent` | `#1f4ed8` | **唯一强调色**：主按钮、链接、选中态（白底对比 6.4:1） |
| `--accent-weak` | `#eef2fd` | 选中行底色 |
| `--ok` | `#0f7a3d` | 满足 / 低风险 |
| `--warn` | `#8a5a00` | 潜在偏离 / 中风险 |
| `--danger` | `#b42318` | 偏离 / 高风险 / 废标风险 |
| `--muted-tone` | `#6b7280` | 未披露 / 证据不足（中性灰） |

> 语义色仅用于状态，且必须**同时**出现图标与文字（`color-not-only`）。不可比状态用「中性灰 + 斜纹/虚线边框 + 图标」表达，不新增色相。

### 3.2 排版与间距

| Token | 值 | 说明 |
| --- | --- | --- |
| `--font-sans` | system-ui, "Segoe UI", "Helvetica Neue", Arial, "Noto Sans SC" | 正文 |
| `--font-mono` | ui-monospace, "Cascadia Mono", Consolas, monospace | 数值、页码、key（`font-variant-numeric: tabular-nums`） |
| 字号 | 12 / 13 / 14 / 16 / 20 / 28 / 36 | 正文 14（<768 升 15） |
| 行高 | 1.5（正文）/ 1.25（标题） | — |
| 圆角 | `0`（卡片、按钮、输入框统一方角） | Swiss 风格 |
| 间距 | 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 | 页面区块 24–32，组件内 8–16 |
| 投影 | 仅弹窗与抽屉使用 `0 8px 24px rgba(17,18,20,.12)` | 其余一律无投影 |

### 3.4 组件契约（实现必须与下表签名一致）

| 选择器 | Inputs | Outputs | 说明 |
| --- | --- | --- | --- |
| `ui-icon` | `name: string`（见 3.5）、`size = 16` | — | 内联 SVG，`aria-hidden` 或 `role=img + aria-label` |
| `ui-btn` | `variant: 'primary'\|'secondary'\|'ghost'\|'danger'`、`size: 'sm'\|'md'`、`loading`、`disabled` | `(click)` 由宿主绑定 | 44 高最小点击区；loading 时禁用并显示 spinner |
| `ui-badge` | `tone: 'ok'\|'warn'\|'danger'\|'info'\|'neutral'\|'dashed'`、`label`、`icon?` | — | 色 + 图标 + 文字三重编码 |
| `ui-stat` | `label`、`value`、`hint?`、`tone?` | — | KPI 卡片，数字用 mono |
| `ui-progress` | `value: number(0-100)`、`tone?` | — | 线性进度条 + 数值 |
| `ui-ring` | `value`、`size = 96`、`label?` | — | SVG 环形，用于资料完整性 |
| `ui-bars` | `data: {label,value,tone?}[]`、`unit?` | — | SVG 柱状图（无第三方库） |
| `ui-heat` | `rows: {name, scores: (number\|null)[]}[]`、`cols: string[]` | — | 优劣势热力图，空格表示不可比 |
| `ui-modal` | `open`、`title`、`size: 'sm'\|'md'\|'lg'` | `(close)` | `role=dialog aria-modal`，Esc 关闭，焦点锁定 |
| `ui-drawer` | `open`、`title`、`side: 'right'\|'left'` | `(close)` | 上传/详情抽屉 |
| `ui-tabs` | `tabs: {id,label}[]`、`active` | `(change)` | `role=tablist`，方向键切换 |
| `ui-empty` | `title`、`hint`、`actionLabel?` | `(action)` | 空态与异常态统一样式 |
| `ui-toast` | —（由 `ToastService.push()` 驱动） | — | 右上角，`aria-live=polite`，4s 自动消失 |
| `ui-confirm` | `open`、`title`、`message`、`danger?` | `(confirm)`、`(cancel)` | 二次确认（批量操作、删除、越权提示） |

**全局 CSS 类（不做成组件，统一在 styles.css）**：`.page`、`.page-head`、`.card`、`.card-hd`、`.table`、`.table-wrap`、`.filter-bar`、`.field`、`.input`、`.select`、`.checkbox`、`.tag`、`.kv`、`.split`、`.stack`、`.row`、`.muted`、`.mono`、`.sr-only`。

### 3.5 图标清单（inline SVG，stroke 1.5）

`grid`（工作台）、`folder`（项目）、`file`（资料）、`search`（原文/检索）、`table`（参数）、`scale`（对比）、`bulb`（研判）、`check-square`（审核）、`doc`（报告）、`library`（情报库）、`settings`（管理）、`chevron-right`、`chevron-down`、`arrow-up`、`arrow-down`、`x`、`check`、`alert`、`info`、`clock`、`user`、`filter`、`download`、`edit`、`link`（证据）、`lock`、`refresh`、`plus`、`menu`。

## 4. 页面规格

### P1 工作台 `/dashboard`

| 区块 | 内容 | 交互 |
| --- | --- | --- |
| 顶部 | 标题「投标工作台」+ 环境标记「演示数据」+ 主行动「新建项目」 | 新建 → 弹窗（归属 `/projects` 同款） |
| KPI 行（4） | 在投项目 3 / 待我审核 5 / 废标风险 2 / 情报条目 128 | 点击跳到对应页并带筛选 |
| 待办区 | 5 条待办（类型、项目、截止、优先级） | 「去处理」跳审核页 |
| 项目卡片区 | 3 个项目卡：国别、规模、截止倒计时、五阶段进度、风险数 | 卡片点击进概览；卡片内「风险 N」跳对比页筛选 |
| 风险摘要 | 高/中/低分布条形 + Top3 风险 | 点击进研判页 |
| 最近活动 | 8 条审计事件（人、动作、对象、时间） | 悬停显示完整描述 |

**状态**：加载骨架（3 卡位）；空态（无项目）；错误态（数据加载失败 + 重试）。

### P2 项目列表 `/projects`

- 视图切换：卡片 / 表格（`ui-tabs`），状态存内存；
- 筛选：国别、阶段、风险等级、搜索框；
- 表格视图：排序（截止日、风险数、进度）、行点击进概览；
- 主行动：新建项目弹窗（字段：名称、客户、国别、MW、MWh、技术路线、截止日、成员）；
- 空态与「清空筛选」动作。

### P3 项目概览 `/projects/:id/overview`

| 区块 | 内容 |
| --- | --- |
| 头部 | 项目名、客户、国别、规模、截止倒计时、阶段徽标；主行动「进入参数矩阵」 |
| 门禁条 | 5 个阶段（摄取→抽取→校验→对比→研判）状态：完成/进行中/未开始/阻塞，附阻塞原因 |
| 资料完整性 | `ui-ring` 87% + 缺项清单（招标文件已上传、缺少 1 份竞对手册、我方资料 2 份） |
| 判定分布 | 六态计数条形（`ui-bars`），点击跳对比页并带状态筛选 |
| 风险摘要 | 高/中/低列表，每项含建议与责任人 |
| 成员 | 头像首字母方块 + 角色徽标 + 最近活动时间 |
| 警示条 | 若缺招标文件或存在未裁决冲突，顶部显示警示并禁用「提交审核」 |

### P4 资料管理 `/projects/:id/documents`

- 主行动「上传资料」→ `ui-drawer`（文件选择模拟 + 类型 + 来源可靠性 + 语言），必填校验；
- 资料表格：名称、类型、来源徽标、页数、质量分（含条形）、解析状态、更新、操作（查看原文/重试/来源详情）；
- 状态筛选：全部/解析中/完成/需核对/失败；搜索；
- 解析异常面板：缺页、跨页表格、低 OCR、图片内参数，四级严重度，支持「去处理」；
- 操作反馈：Toast；重试后状态回到「解析中」再变「完成」（setTimeout 模拟）。

### P5 原文查看器 `/projects/:id/documents/:docId`

- 左右分栏（<1024 上下堆叠）：左侧页面文本（页码、章节标题、正文，命中片段 `<mark>` 高亮），右侧锚点列表（参数名、置信度、页码）；
- 顶部工具条：文件名、类型、页码、章节、置信度、来源可靠性、上一处/下一处；
- 点击锚点 → 左栏 `scrollIntoView` + 高亮；点击正文高亮 → 右栏对应项高亮；
- 操作「原文理解有误」→ 弹窗填理由 → 生成修正建议（Toast + 状态标记）；
- 空态：文档无锚点时提示「该文档尚未抽取」。

### P6 参数矩阵 `/projects/:id/parameters`

- 顶部工具条：搜索、维度筛选、来源筛选、状态筛选、置信度区间、密度切换（舒适/紧凑）；
- 快捷 chip：「待我确认 12」「强制人工 5」「冲突 2」「已修正 4」；
- 表格列：参数（label + mono key）、来源、原始值（mono）、标准化值、条件（chips）、层级、置信度（条 + 数值）、状态、证据、操作；
- 行内编辑：点击「修正」进入编辑态（值/单位/条件/理由必填），保存后状态变更并 Toast；
- 行展开：标准化链路（原值→别名→换算→条件→标准值）+ 校验命中 + 修改历史；
- 批量：勾选 0.60–0.85 项 → 「批量确认」需 `ui-confirm`；<0.60 项复选框禁用并提示；
- 冲突：行内「冲突 N 值」按钮 → 弹窗并列裁决（选择/挂起 + 说明）；
- 空态：无结果时提示放宽筛选。

### P7 对比分析 `/projects/:id/comparison`

- 顶部：维度权重条（技术/性能/安全/质保/交付/商务，合计校验 100）+「应用权重」（默认权重时显著提示）；
- 主行动「导出差距清单」（CSV 下载）；
- 摘要条：废标风险 N、明确偏离 N、不可比 N、未披露 N（点击即筛选）；
- 矩阵表：固定首列与表头；列为 参数｜要求(Mandatory 徽标)｜我方｜竞对列(可勾选显示)｜判定｜优先级；
- 判定单元格：`ui-badge` + 差异说明（截断时 tooltip）+ 证据图标；
- 行展开：判定规则命中详情（规则名、阈值、实际值）、四要素可比性检查表、建议澄清话术；
- 不可比行：整行虚线左边框 + 中性灰徽标，展开显示「为什么不可比」；
- 排序：强制条款 → 偏离 → 不可比 → 其他；顶部明确「本页不提供竞对总排名」；
- 热力图区：`ui-heat`（维度 × 对象），空格=不可比。

### P8 研判与风险 `/projects/:id/insights`

- 顶部：已确认字段 32/60（`ui-progress`）+ 主行动「生成研判」（<15 项时禁用并说明）；
- Tabs：结论卡片 | 风险清单 | 待澄清问题；
- 结论卡片：三段式（结论 / 依据列表 / 类型徽标），操作 采纳 / 修改（理由） / 删除；被拦截的无证据条目在页脚显示计数；
- 风险清单：级别分组（高/中/低），含类型、关联参数、建议处置、责任人、状态；可按级别筛选；
- 待澄清：勾选 → 「复制为文本」（写入剪贴板并 Toast）；
- 决策留白区：`报价让利空间 ____`、`承诺可用率 ____` 输入框 + 说明「由人填写，系统不生成」；
- 空态：未生成时展示引导。

### P9 审核待办 `/projects/:id/reviews`

- 左侧任务列表（类型、优先级、目标、发起人、截止、超期标记），右侧详情；
- 详情：`diff` 双栏（当前值 vs 建议值，变更行高亮）+ 理由快捷选项 + 采纳/驳回/指派；
- 双人规则：若 `editor === currentUser` 且高风险 → 操作禁用 + 说明「需第二审核人」；
- 批量采纳：仅低风险，需 `ui-confirm`；
- 记录时间线：谁在何时做了什么、理由；
- 空态：无待办时显示「当前无待办」+ 最近处理记录。

### P10 报告中心 `/projects/:id/reports`

- 模板卡片 5 张（技术对比报告 / 差距清单 / 证据索引 / 待澄清清单 / 管理层一页简报），含适用对象、章节、预计页数；
- 右侧预览：选中模板后展示模拟内容（标题、段落、表格、证据角标）；
- 发布门禁：未审项 > 0 → 导出按钮禁用 + 列出未审项链接；
- 导出：CSV/文本下载 → Toast + 审计事件；
- 已发布快照列表：版本、时间、作者、水印示例、操作（查看/重新导出）。

### P11 竞品情报库 `/library`

- 左侧竞对列表（6 家：梯队、区域、型号数）；右侧档案；
- 档案内容：基本信息、代表型号表、参数时间线（值/来源/日期/有效期，过时标记）、参与项目与中标结果；
- 检索：关键词 + 维度筛选，命中高亮；空态给建议；
- 只读演示标识（S 级故事）。

### P12 系统管理 `/admin`

4 个 Tab：
1. **用户与权限**：用户表（8 人）+ 权限矩阵（6 角色 × 10 操作，点击单元格切换 允许/只读/禁止），保存 → Toast + 审计；说明「管理员不可读正文」；
2. **参数字典**：48 项表格（key/名称/单位/层级/必需条件/别名数/版本），新增与编辑弹窗，别名管理；
3. **阈值配置**：表单（免检阈值、强制人工阈值、抽检比例、权重默认值、有效期、超时升级），范围校验 + 恢复默认 + 变更说明必填；
4. **审计日志**：30 条事件表（时间、操作人、动作、对象、结果、IP），按类型/人/时间筛选，导出。

## 6. 键盘与无障碍要求

1. 所有交互元素可 Tab 到达，`focus-visible` 显示 2px `--accent` 外框（不与边框重叠）；
2. 弹窗/抽屉打开后焦点移入，Esc 关闭，关闭后焦点回到触发元素；
3. 表格支持键盘上下移动行焦点，Enter 展开；
4. 状态徽标输出 `aria-label`（如「状态：明确偏离」）；
5. 图表提供文字摘要（`aria-label` 或表格替代）；
6. 尊重 `prefers-reduced-motion`：关闭所有过渡与骨架动画。

## 7. 动效规范

| 场景 | 时长 | 曲线 |
| --- | --- | --- |
| 悬停/按压 | 150–200ms | ease-out |
| 抽屉/弹窗进入 | 240ms | ease-out；退出 160ms |
| 行展开 | 200ms | ease-out（仅 opacity + transform） |
| Toast | 180ms 进出 | ease-out |

> 不使用装饰性动画；不做宽度/高度动画；`prefers-reduced-motion` 下全部禁用。
