## 1. 页面目标

### 1.1 要解决的问题

报告中心是「分析做完之后」的最后一环，它不生产新结论，只负责**把已有结论按受众重组、按门禁放行、按版本留痕**。它要解决三件事：

1. **同一份分析服务三种受众**：技术评审组要 18 页参数矩阵、投标经理要 8 页差距清单、管理层只要 1 页态势摘要。现状是把同一份 PPT 剪成三个版本，改一处漏两处，页码引用全失效。
2. **发布前没有硬门禁**：现状"先发出去再说"，未裁决的参数冲突、未通过的高风险审核、无引用的结论会直接进对外文件（BR-01、BR-08），评审会上被问"数据哪来的"答不上（痛点 P-04）。
3. **快照不可追溯**：谁在何时发布了第几版、水印里写了什么、导出过几次，现状查不到，出问题无法定位是哪一版的哪一条。

### 1.2 对应功能（F8）

| 维度 | F8 要求（要点，不复述原文） | 本页落点 |
| --- | --- | --- |
| 用户目标 | 一次分析服务三种受众 | 5 类模板卡按受众分组呈现，一屏可比较 |
| 关键输入 | 已发布快照 | 预览只读已确认字段，未确认字段灰显并计数 |
| 系统逻辑 | 5 类模板；快照渲染；引用角标；水印；脱敏模式 | 第 4 节布局 + 第 5 节字段 + 第 7.5 节水印规则 |
| 输出 | CSV / 文本简报 / 证据索引 | 「导出 CSV」「导出文本简报」两个次行动 + 快照行内重新导出 |
| 异常处理 | 含未审项阻止导出；大表异步生成 | 第 7.4 节发布门禁 + 第 7.6 节超大报告异步 |
| 验收标准 | 每条结论可回链字段；导出 100% 记录审计 | 第 11 节 AC-03、AC-06 |

| 编号 | 成功标准 | 目标值 | 验证方式 |
| --- | --- | --- | --- |

### 4.3 视觉层级与信息密度

- **层级**：页头标题（20）＞ 门禁结论句（16，仅一句）＞ 预览报告标题（20 但位于卡内，视觉权重低于页头）＞ 模板卡名称（13 半粗）＞ 正文（13）。全页只有一个视觉焦点块：门禁横幅。
- **密度**：模板卡区是"选择"而非"阅读"，行高紧凑（卡高 104，内部 4 层信息）；预览区是"核对"，正文行高 1.75、段间距 14，密度低于参数矩阵（该页行高 32）——本页不是用来扫数据的。
- **强调色使用**：全页仅三处用 `--accent`：primary 按钮、选中模板卡边框、预览中证据角标的可点状态。门禁未通过时 primary 按钮降为 disabled 态（保留轮廓，不加投影）。
- **无装饰**：圆角 0、无渐变、无卡片投影；快照表用 1px 上边框与上方区分；分隔用 `--line`，需要「阻断」语义时才用 `--danger` 1px 左边框（4px）。

## 7. 交互细节

### 7.1 模板卡交互

- 点击卡片即切换预览，**不跳转、不刷新整页**；切换时右侧预览淡入 120ms（唯一动效，`prefers-reduced-motion` 下取消）。
- 卡片状态：默认（1px `--line`）／hover（1px `--line-strong` + `--bg-subtle`）／选中（1px `--accent` + `--accent-weak` 底 + `aria-pressed=true`）。
- 键盘：卡片为 `<button>`，Tab 进入组后 ↑↓ 切换、Enter 选中；数字键 `1`–`5` 全局选中对应模板（输入框聚焦时失效）。
- 管理层视角：仅渲染 `tpl-brief` 一张卡，卡上方一行灰字「管理层视角仅提供一页简报，需要完整报告请联系投标经理」，不显示"被隐藏 4 个模板"的计数（避免引导越权）。

### 7.2 预览区交互

| 交互 | 行为 |
| --- | --- |
| 章节折叠 | 章节标题右侧 chevron，点击折叠（默认全展开）；折叠状态在本会话内保持，不写入 URL |
| 密度切换 | 预览头右侧「标准 / 紧凑」二选一，紧凑模式正文 12px/1.6、表格行高 32，用于 1280 宽屏下看完整表 |

### 7.3 门禁清单交互

- 横幅默认展示前 3 条，末行「展开全部 7 项」；展开后按钮变「收起」。
- 每条格式固定：`[G 编号] [类型] [数量] 项 · [最旧一条的对象与标题] · 去处理 →`。示例：`G2 高风险审核未通过 3 项 · task-04「循环寿命承诺条件需法务确认」已超期 1 天 · 去处理 →`。
- 阻断项数量为 0 的门禁**仍显示**（绿色 check + 「已通过」），让评审看到检查过什么，而不是只看到失败项。
- 门禁数据每 60 秒静默重算一次；用户从参数矩阵返回本页时立即重算并 Toast「门禁已更新：未审项 10 → 6」。
- 全部门禁通过时，横幅切换为 `--ok` 左边框的通过态，文案「发布门禁已通过：参数冲突 0 · 高风险审核 0 · 无引用结论 0。导出将写入审计，文件带水印与证据角标。」

- 筛选：快照区标题右侧一个下拉「全部模板 / 技术参数对比 / 差距清单 / …」，选中即过滤；与项目内其他页筛选互不影响。

## 9. 规则引用（BR-* / LR-*）

| 编号 | 规则要点 | 本页落地表现 |
| --- | --- | --- |
| BR-01 | 证据优先，无证据降权并标「无引用」 | 预览中每个数值后带角标 `[n]`；断言无角标时正文该句灰显 + 行尾「无引用」徽标；导出 CSV 中无证据行的证据列写「无引用」而非留空 |
| BR-02 | 缺失不等于零，禁止 0 填充 | 预览表格竞对缺失单元格统一 `—` + tooltip「原文未披露」；CSV 空值写 `—`；文本简报统计行只列有值的判定，不补 0 |
| BR-03 | 未披露不等于不具备，不计劣势 | 预览「差距摘要」章节不含「对手未披露 X 所以弱于我方」类表述；竞对 A 可用率未披露（cmp-003）在预览中记为「未披露」，不进入劣势计数 |
