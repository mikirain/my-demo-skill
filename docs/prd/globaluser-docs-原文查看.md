### 2.2 谁看不到什么（硬规则）

1. **管理层（`exec`）**：侧栏不出现「资料管理 / 原文查看」；直链进入显示权限不足页，文案「本视角不提供原文页，证据请从报告中心的一页简报进入」+「去报告中心」按钮。
2. **系统管理员（`admin`）**：同样不可见（F10 硬约束：管理员不可读文档正文，只能看元数据与审计）。直链拦截并写一条 `aud-0xx`（`action=config`，结果「被拒绝」），页面仅显示文件元数据（名称、页数、哈希、上传人、来源可靠性），正文区以斜纹占位 + 「需技术投标工程师权限」。
3. **商务 / 法务 / 知识库管理员 / 只读观察者**：所有写入型控件**不渲染**（不是禁用）；在原本按钮位置给一行 12px 灰字「修改原文理解需 技术投标工程师 或 投标经理 权限」。
4. **只读观察者**：页首常驻提示条「当前为只读视角，写入操作不可用」，高度 40，`--bg-subtle` 底、1px `--line` 下边框。
5. **双人规则（BR-08）**：本页只发起修正建议，不提供任何「通过 / 采纳」按钮；建议的裁决只在审核待办页由非提交人完成。提交人本人在审核待办看到自己的建议时，通过按钮禁用并说明「提交人不可自审」。
6. **跨项目**：`projectId` 与用户 ACL 不匹配时，不渲染任何正文并跳 404 页变体（`/403?from=documents`），文案**只用通用表述**「当前账号无权访问该项目」，**不得出现项目名与客户名**（与 `globaluser-common-404.md` 的防泄露规则一致）。

### 7.2 锚点 ↔ 正文双向定位

1. **锚点 → 正文**：点右栏卡片 → 左栏滚动使片段位于可视区上 1/3；片段加 `--accent-weak` 底纹与 3px 竖线；卡片进入 `aria-selected` 态（左边框加粗至 3px，不改变颜色语义）。
2. **正文 → 锚点**：点击正文中已标记的片段（片段末尾有 12px 锚点图标）→ 右栏对应卡片滚动到顶部并展开「五元组 + 状态 + 最近变更」；若该片段对应 2 个以上锚点（冲突场景，BR-07），展开为多卡片堆叠，标题显示「同一处原文，2 个取值」。
3. **高亮取消**：Esc 或点击正文空白处；高亮态不自动消失（避免阅读中跳走），但切换锚点时只有一处高亮。

### 10.2 场景叙述一：评审会前 3 分钟的口径仲裁

商务周敏在对比分析里看到「竞对A RTE 92%，我方 88.5%」，准备在评审会上让步报价。她点开该行「原文」，落在 doc-02 的 P.37，片段高亮「up to 92% round trip efficiency measured at DC terminals」。她按 `]` 跳到下一处（P.38），再跳 P.41 看质保拆分，右栏锚点卡把三条置信度并排显示（0.88 / 0.61 / 0.90），低置信的循环寿命是双线边框。她把三段片段用「复制引用片段」拼成一段话发到群里：DC 端子测量、条件待确认、质保拆两段。会上她不再比较效率高低，而是要求对手澄清测量边界——这正是 BR-04 要防的那类误判，整个动作不超过 3 分钟。

### 10.3 场景叙述二：夜间复核 12 个低置信字段

工程师李维在参数矩阵筛出「待复核 12 条」，逐条点证据进入本页。右栏他切成「置信度升序」，第一条 anc-08（0.61）双线边框，展开看到「conditions to be confirmed per project」，正文高亮里没有任何 DoD 与温度数字。他判断这不是数值错误，而是「条件缺失」——打开抽屉，问题类型选「条件缺失」，建议值留空（不填 0），理由写「原文仅给出上限值且条件待确认，不能按 12000 次计入对比」，提交后卡片变「建议待处理 sug-03」。接着 `]` 到下一处，第四条他发现页码归错（锚点 anc-14 落在 P.21 但片段实际在 P.22），用「排除锚点」选「位置错误」，5 秒内确认无误后继续。12 条走完，他在审核待办里看到自己提交的 5 条建议，按 BR-08 全部需要别人裁决，自己的通过按钮是禁用的。

### 10.4 场景叙述三：扫描件兜底不能白屏

doc-13 竞对E 技术应答是 178 页扫描件，质量分 41，解析失败。李维从资料管理 `?status=failed` 点进来，页面没有空白：左栏一张失败卡写明「OCR 平均置信度 0.41 / 121 页无文本层 / 0 条锚点」，右栏写「人工摘录后此处会出现标有『人工摘录』的锚点」。他选「登记人工摘录」，在 640 抽屉里按页码 P.63 录下铭牌 5.02 MWh、P.64 录下 PCS 效率 98.6%，勾选「来源未知，需另一位同事复核」。保存后右栏出现两条虚线边框、标「人工摘录」与「来源未知」的锚点，同时生成两条待审任务。这样竞对E 不会因为解析失败而在对比分析里变成「未披露」的空白——这是 BR-02 与「拒绝静默失败」的具体体现。
