## 1. 页面目标

### 1.1 解决什么问题

项目概览是单项目工作区的**第一屏与守门页**。它不承载编辑，只回答四个问题，且每个答案都能一键下钻到可操作的位置：

1. **这个标现在卡在哪**：五阶段门禁（摄取 / 抽取 / 校验 / 对比 / 研判）的完成、进行中、未开始、阻塞状态，阻塞必须带原因，不允许只显示一个红点。
2. **资料够不够用**：资料完整性得分与缺项清单，明确「缺哪一类、缺到什么程度、影响什么」。
3. **对比到底比出了什么**：六态判定分布（满足 / 潜在偏离 / 明确偏离 / 无法直接比较 / 未应答 / 证据不足 / 未披露），点任意状态直接跳到对比分析并带上筛选。
4. **谁在负责、最近改了什么**：未关闭风险按等级与责任人列示，成员与最近活动提供「谁在何时动了哪个字段」。

同时它承担一个硬性守门职责：**招标文件缺失或存在未裁决冲突时，「提交审核」必须不可用**，并给出可执行的解除路径。

### 1.2 成功标准

| 编号 | 成功标准 | 验证方式 |
| --- | --- | --- |
| S-01 | 投标经理进入本页 30 秒内能说出「当前阶段 + 阻断项数量 + 最严重风险」 | 可用性测试，5 人 / 3 次重复 |
| S-02 | 从判定分布任一状态到对比分析对应筛选结果 ≤ 1 次点击，筛选条件在 URL 中可复现 | 点击路径埋点 + 直接粘贴 URL 验证 |
| S-03 | 提交审核的禁用与原因 100% 与阻断条件一致（无「能点但失败」） | 构造 4 组阻断组合逐条核对 |
| S-04 | 缺项清单每条都能落到「缺什么类型资料」，不出现「资料不完整」这类无行动指向的文案 | 文案走查 |

### 1.3 非目标

- 不在本页做参数修正、冲突裁决、文档上传、结论采纳（各自有专属页面）；
- 不展示报价金额或成本推断，不生成 Go/No-Go 建议（BR-06 决策留白）；
- 不承担经验库、复盘数据的写入（仅提供入口，见第 12 节）。

### 3.3 本页支持的 URL 参数

| 参数 | 取值 | 行为 |
| --- | --- | --- |
| `focus` | `gate` `completeness` `judge` `risk` `activity` | 滚动到对应区块，区块外描边 2px `--accent`，2 秒后淡出；同时设置焦点到区块标题以便键盘继续 |
| `from` | `dashboard` `projects` | 记录来源，第 4 节提到的返回高亮与面包屑层级保持一致；不改变数据 |
| `status` | 六态之一 | 本页不消费，仅作为转出参数；若被外部直接带入，忽略并提示「筛选条件已转移至对比分析」 |

### 4.4 视觉层级

一级 = 页头项目名与阻断警示条（唯一使用 `--danger` 底色块的区域）；二级 = 门禁条（横向进程感，当前阶段用 `--accent-weak` 底）；三级 = 完整性环与判定分布（并列，作为「资料够不够 / 比出了什么」的双入口）；四级 = 风险摘要（文字为主，靠等级徽标形成扫描锚点）；右列全部为辅助信息，字号 12–13。信息密度按「一屏可读」控制：首屏（900 高）必须完整显示 A–D2，D3 允许折叠到首屏下半。

## 5. 数据与字段

### 5.1 数据来源

| 数据源 | 提供内容 | 刷新时机 |
| --- | --- | --- |
| `Project`（项目档案） | 名称、客户、国别、规模、路线、截止日、阶段、成员、完整性 | 进入页面、手动刷新 |
| `Document`（资料） | 类型分布、解析状态、质量分 | 上传 / 解析状态变更后 |
| `ParamValue`（参数实例） | 已确认数、待复核数、冲突数、强制人工数 | 复核动作后 |
| `Gate`（门禁） | 五阶段状态与阻塞原因 | 阶段推进后 |
| `ComparisonRow`（对比行） | 六态计数、强制条款数与废标风险数 | 判定变更后 |
| `RiskItem` / `ReviewTask` | 风险等级与责任人、高风险审核状态 | 处置动作后 |
| `AuditEvent`（审计） | 最近变更 5 条 | 任意写入后 |

派生值一律由后端聚合接口返回，前端不做二次统计（避免与对比分析页数字不一致）。

## 7. 交互细节

### 7.1 门禁条

- 每格点击行为按状态区分：`active` 跳对应页面（摄取→资料管理、抽取/校验→参数矩阵、对比→对比分析、研判→研判与风险）；`blocked` 先展开内联说明（阻塞原因 + 解除条件两条），再给「前往处理」按钮；`done` 打开 popover（产物清单 3 行 + 完成时间 + 完成人），不跳转；`todo` 点击给 Toast「前置阶段未完成，顺序推进」。
- hover 时整格背景 `--bg-subtle`，右上角出现「详情」小图标；支撑键盘：格子为 `button`，`Enter` 激活。
- 状态形状编码：完成 = 顶边 2px 实线 + `check`；进行中 = 顶边 2px 实线 + `clock` + `--accent-weak` 底；未开始 = 顶边 1px 虚线 + `minus`；阻塞 = 顶边 2px 实线（`--danger`）+ `lock` + 浅红底 + 原因行。

### 7.2 资料完整性

- 环形悬停显示「87 / 100，8 项检查中 5 项满分」；点击环或「展开 8 项检查」行内展开 5.3 表格（不弹窗、不跳页），展开状态写入 URL `?focus=completeness` 以便分享。
- 缺项清单默认全展示（≤6 条），每条右侧「去补」：文档类跳 `/documents?missing=<type>`，解析类跳 `/documents?parse=issue`，冲突类跳 `/parameters?tab=conflict`。
- 缺项文案必须写「缺什么 + 影响什么」，例如「竞对标书仅 1 家：横向对比样本不足，竞对 B 的偏差判定只能落在手册口径」。
- 「去补资料」按钮对只读角色不渲染（见 2.2）。

### 7.3 判定分布

- 7 个 chip（六态 + 「全部」）按状态优先级排序：明确偏离 → 无法直接比较 → 潜在偏离 → 未应答 → 证据不足 → 未披露 → 满足；不提供自定义排序。
- 点击 chip 跳 `/comparison?status=<key>&from=overview`，`incomparable` 额外带 `&nocompare=1` 以在目标页展开四要素差异说明。
- 「无法直接比较」chip 使用虚线边框 + `scale` 图标，与对比分析页保持同一形状语言；不可排名状态在 chip tooltip 中写明「不参与排名」。
- 「强制条款」行单列：`7 条强制 · 4 条非满足`，右侧「查看废标风险清单」跳 `/comparison?mandatory=1&risk=1`。
- 维度切换（全部 / 技术 / 性能 / 安全 / 质保 / 交付 / 商务）为分段控件，切换只改本卡计数，不跳页；`commercial` 角色默认锁在商务且可切回全部（只读无副作用）。
- 若某状态计数为 0，chip 仍渲染但为空心描边 + 计数 0，点击提示「当前无该状态行」并不跳转（避免落到空列表）。

### 7.4 风险摘要

- 默认按 等级（高→低）→ 状态（待处理→处置中→已关闭）→ 截止日 排序，展示前 4 条，其余折叠为「展开全部 5 项」。

### 7.5 成员与最近活动
