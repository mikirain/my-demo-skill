测试页面

配色走语义 token，动效只碰 transform / opacity，交互目标全部不小于 44×44。 下面每个组件都对应一条可检查的 UX 规则 —— 点一下就知道它是真的。

开始看组件

01 · interaction

按钮与状态

悬停 180ms、按下缩放到 0.97、异步操作期间禁用并显示进度；禁用态只是「不可点」，不伪装成可点。

点击后按钮禁用 1.4 秒，并播报状态。

02 · forms

表单与校验反馈

可见标签（不是占位符当标签）、失焦后校验、错误贴在字段下方、提交失败自动聚焦第一个出错字段。

用于接收测试报告，不会发送营销邮件。

请输入有效的邮箱地址，例如 you@example.com

至少 8 个字符，建议混合大小写与数字。

密码至少需要 8 个字符

03 · layout

卡片网格

统一圆角、统一描边、统一阴影层级；悬停只上浮 2px，不改变布局尺寸，避免抖动。

性能预算

只动 transform 与 opacity，单帧工作量控制在 16ms 内，首屏不排长任务。

无障碍基线

正文对比度 4.5:1 起，次要文字 3:1 起；语义化标签、可见焦点环、aria 状态全齐。

数据可读

图表配图例、直接标注与可访问表格；不靠颜色单独传递信息。

04 · navigation

标签页

tablist / tab / tabpanel 语义齐全，支持左右方向键切换，当前项有明确选中态。

  • 深色底不是纯 #000，避免 OLED 拖影；层级用「深 → 浅」三段背景表达。
  • 强调色仅用于主要操作与数据，装饰不使用品牌色。
  • 图标统一 24 栅格、2px 描边，不用 emoji 当图标。
  • 微交互 150–300ms，进入 ease-out，退出更快。
  • 按下缩放 0.97，释放回 1，不移动周围元素。
  • 动画可被打断，输入期间界面始终可操作。
  • 减少动态：prefers-reduced-motion 下全部动效降到 1ms。
  • 焦点环 3px 并留 2px 偏移，键盘全流程可达。
  • 错误用 role="alert"，状态用 aria-live="polite"。

08 · pre-delivery

交付前自检

按 CRITICAL → HIGH → MEDIUM 的顺序过一遍，重点在前三档。

  • 图标全部为内联 SVG，无 emoji 当图标
  • 可点元素均有 cursor: pointer
  • 悬停/状态过渡 150–300ms
  • 正文对比度 ≥ 4.5:1，次要文字 ≥ 3:1
  • 键盘焦点环可见（3px + 2px 偏移）
  • prefers-reduced-motion 下动效关闭
  • 触控目标 ≥ 44×44（含图标按钮）
  • 375 / 768 / 1024 / 1440 无横向滚动
